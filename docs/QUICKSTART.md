# Quick Start – Termux Python IDE

## Prereqs
- Android 8+ recommended
- Install Termux from F-Droid
- Enough storage (~1 GB safe)

## Install
```bash
pkg update -y && pkg upgrade -y
pkg install -y git
cd ~
git clone https://github.com/USERNAME/termux-python-ide.git
cd termux-python-ide/termux
bash bootstrap.sh

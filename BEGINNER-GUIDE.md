# Beginner’s Quick Reference – Termux + Neovim + Python

## Termux Basics
- **`pkg update -y`** – Update package list.
- **`pkg install <package>`** – Install a package.
- **`ls`** – List files in current folder.
- **`cd <folder>`** – Change directory.
- **`python file.py`** – Run Python file.

## Neovim Basics
- **`i`** – Insert mode (start typing).
- **`Esc`** – Exit insert mode.
- **`:w`** – Save file.
- **`:q`** – Quit Neovim.
- **`:wq`** – Save and quit.

## Custom Key Bindings
- **`<Space>r`** – Run Python file.
- **`<Space>f`** – Auto-format code.
- **`<Space>l`** – Lint file.

## Tips for Mobile
- Enable the extra keys row in Termux for `Esc` and arrows.
- Use `<Space>` leader key to avoid complex key combos.
- Volume-Up + E = Esc (custom Termux
